Où trouver mon token ? 🔎

  1. Va sur efe.tspro.fr et connecte-toi normalement.
  2. Clic droit n'importe où sur la page → Inspecter (ou touche F12).
  3. Dans la fenêtre qui s'ouvre, onglet Application tout en haut.
  4. Colonne de gauche : Storage → Local storage → https://efe.tspro.fr.
  5. Ligne student_token : copie tout ce qu'il y a dans la colonne Value.
  6. Colle-le dans le champ ci-dessus, et voilà 👍

Le token reste sur ce PC (dans le localStorage du navigateur), il n'est envoyé qu'à efe.tspro.fr.
